# Status

This project is currently under development.

# Use Case

An e-commerce website that displays the key insights for its business. 

The ETL pipeline will extract data from external sources, transforms and cleans it, then loads it into PostgreSQL.
The Django backend will expose the data through an API, while the Svelte frontend uses it and provides the user interface and data visualizations.

# Stack used

- **Backend :** Django
- **Frontend :** Svelte
- **Database :** PostgreSQL
- **Containerization :** Docker
- **Version control :** Git
- **Environnement :** .env
